## Process (5 étapes)

1. **Audit** sur place tablette (5 min, gratuit) → skill `audit-eatbu`
2. **Maquette** envoyée 7j après → skill `maquette-flash` (à venir)
3. **Devis + signature** (acompte 30%)
4. **Build** 10j → skill `site-from-brief` (à venir)
5. **Livraison** + formation 30 min + photo Instagram du patron

## Stack technique

- **Astro** (sites statiques ultra-rapides, top SEO local)
- **Decap CMS** (édition autonome par le client, gratuit, git-based)
- **Cloudflare Pages** (hébergement gratuit illimité, CDN mondial)
- **Plausible** ou Cloudflare Analytics (stats sans cookies)

Coût d'hébergement par site client livré : **0€/mois**.
