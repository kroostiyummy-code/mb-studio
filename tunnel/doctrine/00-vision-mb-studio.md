# 00 — Vision MB Studio

## Qui je suis

MB Studio est un studio de création digitale dirigé par Mike, basé en France. La cible principale est la restauration locale indépendante : restaurants, foodtrucks, bistrots, commerces de bouche en TPE.

L'objectif n'est pas de faire "des sites web". L'objectif est de **rendre justice au vrai potentiel des commerces locaux** en leur donnant une vitrine digitale qui ressemble à ce qu'ils sont réellement, et qui convertit les passants en clients.

## Pourquoi MB Studio existe

Le marché des sites pour restaurants est saturé de trois mauvaises offres :

1. **Les générateurs automatiques** (eatbu.com, dish.co, restaurant.io) : sites moches, génériques, qui font tous le même rendu, qui ne reflètent jamais l'âme du lieu.
2. **Les agences web généralistes** : trop chères (2000-5000€), trop lentes (2-3 mois), focalisées sur le design abstrait plus que sur le commerce local.
3. **Le "neveu qui fait du web"** : amateur, instable, sans process, livraison aléatoire.

**MB Studio occupe un quatrième espace** : sites sur mesure, livraison rapide (5-7 jours), prix accessible TPE (590€ à 1 490€), qualité supérieure aux générateurs, sans le coût d'une agence.

## Le principe non-négociable : l'unicité

**Aucun site MB Studio ne ressemble à un autre.** Jamais.

C'est notre promesse commerciale fondamentale, et c'est ce qui justifie le prix. Si on tombe dans le template, on perd ce qui nous différencie. On devient eatbu en plus cher.

Concrètement :
- Pas de template visuel partagé entre clients
- Direction artistique pensée pour chaque lieu spécifiquement
- Copywriting sensoriel propre à chaque atmosphère
- Structure de site adaptée à la fonction réelle du commerce
- Garde-fou inter-clients : 2 restos jamais sur la même combinaison [palette + typo + structure + ton]

## La méthode : atmosphère first

Notre méthodologie tient en une phrase :

> **"The website must feel like a physical place before it feels like a website."**

Le site doit faire ressentir le lieu avant d'expliquer l'offre. L'ordre mental est :

1. **Atmosphère** (ce qu'on ressent)
2. **Sensation** (l'émotion produite)
3. **Espace** (la projection mentale dans le lieu)
4. **Rythme** (la vitesse de l'expérience)
5. **Interface** (les éléments fonctionnels)

Si on inverse cet ordre, on produit un site web. Si on respecte cet ordre, on produit une **vitrine émotionnelle** qui donne envie de venir.

## Les 3 piliers techniques

1. **Mobile-first absolu** : 80% des consultations restaurants se font sur mobile. Tout site qui n'est pas pensé d'abord pour 375px de large est cassé d'origine.
2. **SEO local intégré** : ville + type de cuisine + spécialité dans les meta, schema.org Restaurant complet, ancrage géographique dans le copy.
3. **Performance et autonomie** : hébergement gratuit Cloudflare Pages, pas de dépendance à un CMS payant, pas d'abonnement obligatoire pour le client.

## Les 3 anti-patterns refusés

1. **Le design vide** : sections vides qui respirent juste pour faire "premium". On préfère la densité sensorielle juste à la respiration artificielle.
2. **Le copy générique** : "expérience unique", "produits frais", "équipe passionnée", "incontournable". Ces mots sont morts.
3. **L'imitation de l'agence chic** : on ne fait pas du Sketch.com pour kebab. On fait du Pink Mamma pour kebab, du Coya pour méditerranéen, du Bonnie pour gastro. Le luxe froid tue le commerce local.

## L'output type d'un site MB Studio

Quand un site MB Studio est livré, le restaurateur doit pouvoir dire :

> **"C'est mon resto. Vous l'avez vraiment compris."**

Et quand un passant tombe dessus sur mobile, il doit pouvoir se dire :

> **"J'ai envie d'y aller."**

Si ces deux phrases ne sont pas vraies, le site est raté, peu importe sa qualité technique.

## Le rôle des agents IA dans MB Studio

Le pipeline de production utilise plusieurs agents IA spécialisés en chaîne :

1. **Agent 1 — Fiche restaurant** : recherche et structure l'identité du lieu
2. **Agent 2 — Copywriting** : produit les textes sensoriels et SEO
3. **Agent 3 — Prompt Stitch** : génère le brief de direction artistique pour Stitch

Ces agents ne sont pas des outils pour gagner du temps. Ce sont des **collaborateurs spécialisés** qui appliquent la doctrine MB Studio à chaque étape. Ils doivent connaître :
- La vision (ce document)
- La méthode émotionnelle (les 10 axes)
- L'anti-jumeau (la garantie d'unicité)
- Les références cinématographiques (les modèles d'inspiration)

Sans cette doctrine partagée, ils produisent du générique. Avec elle, ils produisent du MB Studio.
